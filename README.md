# Scopo
Questa repository è riferita alla tesi di dottorato di Luisa Troncone, XXXIX ciclo, Università di Salerno/Lille (tutrice: Miriam Voghera, co-tutrice: Paola Pietrandrea), dal titolo: _Il parlato che non c'era: modalità, lingua e interazione nell'italiano di TikTok_

# Contenuti
In questa repository ho caricato  i codici utilizzati per l'interrogazione dei corpora scelti per l'analisi. 

I codici sono stati redatti  a partire da architettura ideata dall'autrice in congiunzione con gli strumenti di intelligenza artificiale Gemini e Claude (nelle versioni disponibili nell'inverno 2025 e nella primavera 2026), rivisti, modificati e verificati dall'autrice.
