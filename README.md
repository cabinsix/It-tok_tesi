# Scopo
Questa repository è riferita alla tesi di dottorato di Luisa Troncone, XXXIX ciclo, Università di Salerno/Lille (tutrice: Miriam Voghera, co-tutrice: Paola Pietrandrea), dal titolo: _Il parlato che non c'era: modalità, lingua e interazione nell'italiano di TikTok_
# Contenuti
In questa repository ho caricato tutti i codici utilizzati per l'interrogazione dei corpora scelti per l'analisi. I codici sono stati redatti in congiunzione a partire da architettura ideata dall'autricecon gli strumenti di intelligenza artificiale Gemini e ChatGPT, rivisti e verificati dall'autrice.
